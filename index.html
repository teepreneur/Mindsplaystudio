    Why MindsPlay

    Play first. The learning is inside.

    Most learning apps are worksheets in a costume. We start the other way round: we build a game worth playing, then put a real skill at the heart of how you win.

    01.

    Real skills, not busywork

    Every game is built around skills you use at school and in life. In Xed, every quest is a real maths question from the curriculum.

    02.

    Grows with you, 6 to 17

    Our games line up into a path: start with counting at six, finish running a business at seventeen. Each game adapts to how you play.

    03.

    Made for here

    African heroes, places, voices and money. Built in Accra by people who grew up here, for players across the continent.

    04.

    Safe by design

    No ads. No loot boxes. No chat with strangers. Gear is earned by playing, never bought with real money.

    05.

    Progress you can see

    Players see their stats. Parents and teachers see the skills behind them, skill by skill.

    06.

    Built with players

    Kids and teens test every game before it ships. Our playtest crew shapes what we make next.

    How we build

    Every MindsPlay game follows four rules.

    1. Fun has to work alone

      If the game isn’t fun without the learning, we don’t ship it. Players test it first.

    2. The skill is the mechanic

      You win by using the skill. In Xed, a bridge plank only fits if it makes 10.

    3. It adapts to you

      Too easy gets harder, too hard gets a lesson. No one gets stuck or bored for long.

    4. Growth is visible

      Players see stats and badges. Parents and teachers see which skills are mastered.
