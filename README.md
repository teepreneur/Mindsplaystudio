# MindsPlay Studios website

Static site for MindsPlay Studios and its first game, Xed. Served with GitHub Pages from the `main` branch.

- `index.html` is the studio home page
- `xed.html` is the Xed game page; `lamplight.html`, `graned.html`, `inkbound.html`, `sworld.html` and `brightside.html` are the other games' pages
- `signup.html`, `account.html` (parents: children, games, class codes, payments), `player.html` (players: sign up, ask a parent, their games and awards), `download.html`, `play.html` (browser demo), `admin.html`, `terms.html`; `app.js` / `app.css` are shared and talk to api.mindsplaystudiogh.com
- `img/` holds screenshots and the animated hero loop
