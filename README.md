# MindsPlay Studios website

Static site for MindsPlay Studios and its first game, Xed. Served with GitHub Pages from the `main` branch.

- `index.html` is the studio home page
- `xed.html` is the Xed game page
- `signup.html`, `account.html` (parents: children, class codes, payments), `download.html`, `play.html` (browser demo), `admin.html`, `terms.html`; `app.js` / `app.css` are shared and talk to api.mindsplaystudiogh.com
- `img/` holds screenshots and the animated hero loop
